# iCON + Ableton: контроллер следует за выбранной дорожкой

Это официальный скрипт iCON v1.16 с одним добавлением: кликаешь дорожку в Ableton, и она становится первой на контроллере. Следующие дорожки идут за ней.

Подходит для P1-Nano, P1-X, P1-M, V1-M и V1-X.

## Установка

Закрой Ableton и выполни в Терминале:

```bash
git clone https://github.com/po-sc/icon-ableton-follow.git
cd icon-ableton-follow
cp -R Icon_V_and_P_Series_Ableton_Follow* ~/Music/Ableton/User\ Library/Remote\ Scripts/
```

На Windows после `git clone` скопируй папки `Icon_V_and_P_Series_Ableton_Follow*` в `Документы\Ableton\User Library\Remote Scripts\`.

Репозиторий приватный, поэтому нужен доступ к нему и вход в GitHub.

## Настройка

1. Открой Ableton: **Settings → Link, Tempo & MIDI**.
2. В первой строке выбери:
   - **Control Surface:** `Icon_V_and_P_Series_Ableton_Follow`
   - **Input и Output:** порт контроллера, например `iCON P1-Nano (Порт 1)`
3. Перезапусти Ableton.
4. На контроллере нажми кнопку **DAW 1**.

Подключай контроллер напрямую к компьютеру, без хаба и USB монитора.

## Несколько контроллеров

Каждому блоку нужна своя строка. Порядок строк задаёт порядок блоков слева направо.

- Основному блоку (P1-M, V1-M, P1-Nano) выбери `Icon_V_and_P_Series_Ableton_Follow`.
- Экстендерам (P1-X, V1-X) выбери по порядку `..._Follow_XT1`, `_XT2`, `_XT3`.
- Один и тот же скрипт нельзя выбрать дважды.
- При первом включении нажми **Record 1** на первом блоке, **Record 2** на втором и так далее.

| Схема | Строка 1 | Строка 2 | Строка 3 | Строка 4 |
|---|---|---|---|---|
| P1-Nano | P1-Nano | | | |
| P1-Nano + P1-X | P1-Nano | P1-X (`XT1`) | | |
| P1-M + P1-X | P1-X (`XT1`) | P1-M | | |
| P1-M + два P1-X | P1-X (`XT1`) | P1-M | P1-X (`XT2`) | |
| P1-M + три P1-X | P1-X (`XT1`) | P1-M | P1-X (`XT2`) | P1-X (`XT3`) |
| V1-M + V1-X | V1-M | V1-X (`XT1`) | | |
| V1-M + два V1-X | V1-M | V1-X (`XT1`) | V1-X (`XT2`) | |
| V1-M + три V1-X | V1-X (`XT1`) | V1-X (`XT2`) | V1-M | V1-X (`XT3`) |

## Как проверить

- Кликни дорожку: её имя появится на первом канале, а фейдер приедет на её громкость.
- Нажми Bank: дорожки сдвинутся и останутся там, пока не выберешь другую.
- Запусти воспроизведение: красные цифры покажут время, например `001.01.01.000`.

## Цвета дорожек

Скрипт всегда отправляет цвета на контроллер. По описанию iCON их показывают внешние экраны: D5 для P1-Nano, D4 для P1-X и D4T для P1-M. Маленький встроенный экран P1-Nano показывает только имя, значения и уровни.

## Кнопки тачскрина

Этот шаг нужен только для кнопок на тачскрине.

1. Открой iMap и выбери Ableton.
2. На вкладке **Button Functions** нажми правой кнопкой мыши вне кнопок.
3. Выбери **Load DAW Mapping** и загрузи файл своей модели из папки `iMap`.

Там же лежит оригинальная инструкция iCON с картинками.

## Обновление

В папке `icon-ableton-follow` выполни:

```bash
git pull
cp -R Icon_V_and_P_Series_Ableton_Follow* ~/Music/Ableton/User\ Library/Remote\ Scripts/
```

Потом перезапусти Ableton.

## Что исправлено

Кроме слежения за дорожкой, здесь исправлены ошибки оригинала:

- Bank больше не уводит за последнюю дорожку.
- Mute, Solo и Rec обновляются при добавлении и удалении дорожек.
- Красные цифры показывают время без чёрточек.
- Цвета в режиме Send не остаются от дорожек.
- Кольца ручек в режиме Input гасятся правильной командой.
- Старый экземпляр скрипта отключается от Ableton.

## Если не работает

- **Скрипта нет в списке:** проверь, что папка лежит прямо в `Remote Scripts`, и перезапусти Ableton.
- **Контроллер не реагирует:** проверь кнопку DAW 1 и порт.
- **Каналы начинаются с девятой дорожки:** скрипт стоит не в первой строке.
- **Контроллер отключается:** подключи его напрямую к компьютеру.
- **Нужно вернуть как было:** выбери прежний скрипт в той же строке.

Ошибки записываются в `~/Library/Preferences/Ableton/Live <версия>/Log.txt`.

## Что проверено

На P1-Nano скрипт загружается в Ableton 12.4 без ошибок. Остальные модели и экраны проверены только тестами, без настоящих устройств.
