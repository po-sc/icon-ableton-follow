# Инструкция по установке: iCON V & P Series Ableton + Follow

Это официальный скрипт iCON v1.16 с одним добавлением: выделяешь дорожку в Ableton, и она становится первой на контроллере, а следующие идут за ней. Цвета, режимы, экраны и экстендеры остаются от оригинала.

Поддерживаются V1-M, V1-X, P1-M, P1-X и P1-Nano.

**Статус:** скрипт проверен тестами на макете Ableton, на реальном контроллере подтверждение ещё не получено.

## Перед установкой

- **USB:** подключайте контроллер напрямую к компьютеру, без хабов и USB монитора.
- **Ableton:** iCON рекомендует последнюю версию. Эта сборка тестировалась с кодом Live 12.
- **iMap:** в iCON iMap назначьте Ableton как DAW для контроллера.
- **Прошивка:** iCON рекомендует последнюю версию. Если обновляете, не отключайте контроллер в процессе.

## Что в архиве

| Файл | Зачем нужен |
|---|---|
| `Icon_V_and_P_Series_Ableton_Follow` | Скрипт основного блока, нужен всегда |
| `Icon_V_and_P_Series_Ableton_Follow_XT1`, `_XT2`, `_XT3` | Скрипты экстендеров, нужны только с экстендерами |
| `Icon P1N … .p1n-daw`, `Icon P1M … .p1m-daw`, `Icon V1M … .v1m-daw` | Маппинги кнопок для iMap |
| `color_test.swift` | Проверка цветов на экране, только macOS |
| `Instruction Ableton.pdf` | Оригинальная инструкция iCON с картинками |

## 1. Установка скрипта

1. Закройте Ableton.
2. Скопируйте нужные папки сюда:
   - **macOS:** `~/Music/Ableton/User Library/Remote Scripts/`
   - **Windows:** `Документы\Ableton\User Library\Remote Scripts\`
3. Запустите Ableton.

Оригинальная инструкция на macOS советует папку внутри приложения. `User Library` тоже подходит, и скрипт не пропадёт при обновлении Live.

## 2. Выбор скрипта в Ableton

1. Откройте **Settings → Link, Tempo & MIDI**.
2. В первой строке **Control Surface** выберите `Icon_V_and_P_Series_Ableton_Follow`.
3. В **Input** и **Output** той же строки выберите порт контроллера, для одного контроллера это **Порт 1**.
4. На контроллере включите **слот DAW 1**.

Для одного порта выбирайте только один скрипт. Оригинальный скрипт iCON можно не удалять, но на этом порту он должен быть выключен.

## 3. Маппинг кнопок в iMap

Этот шаг нужен для кнопок на тачскрине. Слежение и цвета работают и без него.

1. Откройте iMap и выберите **Ableton** как DAW.
2. Откройте вкладку **Button Functions**.
3. Нажмите правой кнопкой мыши вне кнопок и выберите **Load DAW Mapping**.
4. Загрузите файл для своей модели.

По инструкции iCON другие DAW-слоты при этом сохраняются, но перед загрузкой лучше сохранить текущую настройку через **Save File**.

## 4. Проверка

1. **Слежение:** кликните дорожку в Ableton. Её имя появится на первом канале, а фейдер этого канала приедет на её громкость.
2. **Цвета:** покрасьте дорожку в Ableton. Если экран умеет показывать цвета, цвет её канала сразу изменится.
3. **Bank:** нажмите Bank. Дорожки сдвинутся и останутся на месте, пока вы не выберете другую дорожку.

Чтобы отдельно проверить экран на macOS, закройте Ableton и запустите `swift color_test.swift` из папки архива. 20 секунд контроллер будет показывать цвета и надписи `P1 CH 1..8`. Цифра после `P` показывает номер порта активного слота.

Для P1-Nano iCON цвета на встроенном экране не заявляет, поэтому их там может не быть. Слежение от этого не зависит.

## 5. Несколько контроллеров

Каждому блоку нужен свой порт и своя строка Control Surface: строка 1 с портом 1, строка 2 с портом 2 и так далее. Номер строки задаёт позицию блока, поэтому порядок важен.

Основному блоку выберите скрипт `…_Follow`, экстендерам по порядку `…_Follow_XT1`, `_XT2`, `_XT3`. При первом включении задайте порядок блоков: **Record 1** на первом, **Record 2** на втором и так далее.

| Схема | Дорожек | Порты |
|---|---|---|
| P1-Nano | 8 | P1-N (Порт 1) |
| P1-Nano + P1-X | 16 | P1-N (Порт 1), P1-X2 (Порт 2) |
| P1-M + два P1-X | 24 | P1-X1 (Порт 1), P1-M (Порт 2), P1-X3 (Порт 3) |
| V1-M + один V1-X | 16 | V1-M (Порт 1), V1-X2 (Порт 2) |
| V1-M + три V1-X | 32 | V1-X1 (Порт 1), V1-X2 (Порт 2), V1-M (Порт 3), V1-X4 (Порт 4) |

## Если что-то не работает

- **Скрипта нет в списке:** проверьте, что папка лежит прямо в `Remote Scripts`, а не во вложенной папке, и перезапустите Ableton.
- **Контроллер не реагирует:** проверьте слот DAW на контроллере и порт в строке Control Surface.
- **Каналы начинаются с девятой дорожки:** скрипт стоит не в первой строке.
- **Контроллер отключается:** подключите его напрямую к компьютеру.
- **Нужно вернуть как было:** выберите прежний скрипт в той же строке Control Surface.

Ошибки записываются в `Log.txt`: на macOS он лежит в `~/Library/Preferences/Ableton/Live <версия>/`.
